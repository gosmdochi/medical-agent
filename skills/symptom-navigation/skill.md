# 증상 안내 절차 (Symptom Navigation Skill)

사용자가 신체 증상을 언급하면, 아래 6단계를 **순서대로** 진행하세요.
각 단계를 건너뛰지 말고, 이전 단계의 결과를 다음 단계의 입력으로 사용합니다.

## 진행 원칙

- 한 번에 모든 단계를 답하지 말고, 각 단계마다 필요한 정보를 사용자에게 확인한 뒤 다음 단계로 넘어가세요.
- 사용자가 대화 중간에 새로운 증상을 추가로 언급하면, 2단계(응급 여부 판단)부터 다시 검토하세요.
- 참고 정보를 제공하는 도구의 응답에는 "참고용이며 진단·처방을 대체하지 않는다"는 안내 문구가
  disclaimer_guard_middleware에 의해 자동으로 보강됩니다. 별도로 반복해서 강조할 필요는 없습니다.

## 1단계 — 증상 입력 수집

- 사용자가 말한 증상(부위, 양상, 지속 기간, 강도)을 정리해 되짚어 확인하세요.
- 증상이 모호하면("몸이 안 좋아요") 구체적인 부위나 양상을 한 가지만 짚어 물어보세요.

## 2단계 — 응급 여부 판단

- emergency_screening_middleware가 명백한 응급 키워드는 이미 최우선으로 걸러냅니다.
  응급 신호가 감지된 경우, 이 절차의 나머지 단계는 진행하지 말고
  즉시 119 신고 또는 가까운 응급실 방문 안내에 집중하세요.
- 키워드로 명확하지 않지만 애매한 경우, search_symptom_info 도구로 증상의
  심각도·동반 위험 신호를 확인한 뒤 응급 여부를 판단하세요.
- 응급이 아니라고 판단되면 3단계로 진행하세요.

## 3단계 — 진료과 추천

- recommend_department(symptom) 도구를 호출해 적절한 진료과를 1~2개 추천하세요.
  (예: 내과, 이비인후과, 정형외과, 피부과 등)
- 증상이 여러 진료과에 걸치는 경우, 가장 관련성이 높은 순서로 안내하세요.

## 4단계 — 병원 찾기

- find_hospital(department, location) 도구로 추천된 진료과를 진료하는
  사용자 인근 병원을 검색하세요.
- 사용자의 지역 정보가 없으면, 먼저 "어느 지역(예: OO시 OO구)에서 찾아드릴까요?"라고 물어보세요.
- 검색 결과는 2~3곳으로 추려서 이름/주소/거리 위주로 간결하게 제시하세요.

## 5단계 — 오늘 진료 여부 확인

- check_hospital_hours(hospital_id, date=오늘) 도구로 선택된 병원(들)의
  오늘 진료 여부와 진료 시간을 확인하세요.
- 오늘 진료가 불가능한 경우, 대안 병원 또는 다음 진료 가능일을 함께 안내하세요.
- 휴진/응급실 운영 여부 등 특이사항이 있으면 반드시 언급하세요.

## 6단계 — 병원 방문 체크리스트 제공

- generate_visit_checklist(symptom, department) 도구로 방문 전 준비물 및
  확인사항 체크리스트를 생성해 전달하세요.
- 체크리스트에는 최소한 다음 항목을 포함하세요:
  - 신분증, 건강보험증
  - 복용 중인 약물 목록 (있는 경우)
  - 증상 메모 (발생 시점, 양상, 변화 추이)
  - 사전 예약 필요 여부
- 체크리스트 제공을 끝으로 이번 절차를 마무리하고, 추가 질문이 있으면 언제든 도와줄 수 있음을 안내하세요.

## 종료 조건

- 사용자가 "됐어요", "그만할게요" 등 종료 의사를 밝히면 절차를 즉시 중단하고,
  필요하면 언제든 다시 요청할 수 있음을 짧게 안내하세요.
- 사용자가 이미 특정 단계 정보를 먼저 제공한 경우(예: 진료과를 스스로 지정), 해당 단계는
  다시 묻지 말고 다음 단계로 바로 진행하세요.
